## About the project

This repository serves as a solid foundation for building modern web applications with an organized structure and development tools already in place. The project includes:

- Next.js with App Router
- React 19 and TypeScript
- Tailwind CSS for styling
- Jest and Testing Library for unit tests
- ESLint, Prettier, and Husky for code consistency

## Installation

Requirements:

- Node.js 20+
- pnpm 9+

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

To run the project locally with HTTPS, use:

```bash
pnpm dev:https
```

## Favicon generation

The project uses RealFaviconGenerator to create the favicon assets from
`favicon/logo.svg`. The generated files are written to `public/`:

```bash
pnpm favicon:build
```

To use a different logo, update `favicon/logo.svg`. To adjust the generated
assets, edit the configuration in `favicon/generate.ts`, then run the command
again. The `site.webmanifest` generated by the tool is removed after the
command completes because the application's manifest configuration is defined
in `src/app/manifest.ts`.

## Useful scripts

| Script               | Description                      |
| -------------------- | -------------------------------- |
| `pnpm dev`           | Start the development server     |
| `pnpm build`         | Create a production build        |
| `pnpm start`         | Run the production build locally |
| `pnpm test`          | Run unit tests                   |
| `pnpm test:watch`    | Run tests in watch mode          |
| `pnpm test:coverage` | Run tests with coverage report   |
| `pnpm lint`          | Run ESLint checks                |
| `pnpm typecheck`     | Run TypeScript type checking     |
| `pnpm format`        | Format the project files         |
| `pnpm favicon:build` | Generate favicon assets          |

## Testing
